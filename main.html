CH 0402 / 05

while Loops

A while loop keeps running as long as its condition is True. Always make sure the condition eventually becomes False to avoid an infinite loop!

PYTHON
# Runs 5 times
i = 1
while i < 6:
    print(i)
    i = i + 1

# Runs once (hungry set to False)
hungry = True
while hungry:
    print("Time to eat!")
    hungry = False

CH 0403 / 05

break & continue

break exits the loop immediately. continue skips the rest of the current iteration and jumps to the next one.

BREAK
nums = [0, 254, 2, -1, 3]
for n in nums:
    if n < 0:
        print("Negative!")
        break
    print(n)
# 0, 254, 2, Negative!
CONTINUE
big = [1, 2, -1, 4, -5, 5]
for i in big:
    if i < 0:
        continue
    print(i)
# 1, 2, 4, 5

CH 0404 / 05

Nested Loops & Comprehension

Nested loops loop inside loops — great for 2D data. List comprehensions create lists in one compact line.

NESTED
groups = [["Jobs","Gates"],
          ["Newton","Euler"]]
for group in groups:
    for name in group:
        print(name)
COMPREHENSION
# Squares of even numbers 0-9
result = [x**2 for x in range(10)
          if x % 2 == 0]
print(result)
# [0,4,16,36,64]

Variable Scope

A local variable only exists inside the function. A global variable is defined outside and accessible everywhere.

LOCAL vs GLOBAL
a = 5         # global

def f1():
    a = 2     # local — shadows global
    print(a)  # 2

print(a)  # 5 — global unchanged
f1()      # 2

CH 0504 / 05

Returning Multiple Values

A Python function can return more than one value by separating them with commas. The values come back as a group you can unpack into individual variables.

MULTIPLE RETURN
def square_point(x, y, z):
    x_sq = x * x
    y_sq = y * y
    z_sq = z * z
    return x_sq, y_sq, z_sq

a, b, c = square_point(3, 4, 5)
print(a)  # 9
print(b)  # 16
print(c)  # 25

What is a String?

A string is a sequence of characters — letters, numbers, symbols, whitespace. Written inside 'single' or "double" quotes. Strings are immutable — once created, they can't be changed in place.

  • →Any length, any character: "hello", "42", "hi! 🐍"
  • →Immutable — .upper() always returns a new string, never modifies the original
  • →Check the type: type("hello") → <class 'str'>
PYTHON
name  = "Alice"
grade = 'A+'
emoji = "learning 🐍"
